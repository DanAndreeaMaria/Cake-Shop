# Cake-Shop

This project is a visually appealing and user-friendly cake shop webpage built using HTML and CSS. The website features multiple sections, including **Home, About, Sweets, Prices** and **Contact** each designed to provide an engaging user experience.

## Features

  * **Navigation menu:** Easy-to-use menu with icons for different sections
  * **Hero section:** A welcoming banner with a logo
  * **About section:** Brief information about the cake shop
  * **Sweets section:** Showcases images and descriptions of delicious sweets
  * **Prices section:** Displays a menu with cakes and their respective prices
  * **Contact section:** Includes address details and a Google Maps integration

## Technologies used

  * **HTML5:** For structuring the webpage
  * **CSS3:* For styling, including responsive design and animations

## Responsive design

  * The website is optimized for both desktop and mobile screens using media queries
